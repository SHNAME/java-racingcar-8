## 🚗 프로젝트 개요 - 자동차 경주

---

- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름 부여 가능 → 출력할 때 자동차의 이름을 전진 횟수와 함께 출력한다.
- 자동차의 이름은 쉼표(,)로 구분하며 이름은 최대 5 글자 이하만 가능하다.
- 사용자는 자동차 이름을 입력 후 경기 횟수를 입력한다.
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지 알려준다. 우승자는 2명 이상일 수 있으며 여러 명일 경우 쉼표(,) 를 이용하여 구분한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumnetException 예외를 발생시킨 후 애플리케이션은 종료되어야 한다.

---

### 입출력 요구 사항

***입력***

- 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)

``` 
pobi,woni,jun
```

- 시도할 횟수

```
5
```

***출력***

- 차수별 실행 결과

```
pobi : --
woni : ----
jun : ---
```

- 단독 우승자 안내 문구

```
최종 우승자 : pobi
```

- 공동 우승자 안내 문구

```
최종 우승자 : pobi, jun
```

**실행 결과 예시**

```

시도할 횟수는 몇 회인가요?
```

## 📄 기능 구현 목록

### 자동차 이름 요청 문구 출력 기능

- [x] 뷰에서 사용자에게 안내 메세지를 출력한다.
- [x] 사용자에게 자동차 이름에 대한 안내 메세지 출력을 위한 함수를 구현한다.

### 자동차 이름  입력 기능

- [x] 뷰에서 자동차의 이름을 입력 받는다.
- [x] 사용자로부터 문자열을 입력 받는 함수를 구현한다.
- 입력의 유효성을 검증한다.
    - 입력 단에서 검증
        - [x] 빈 문자열이 입력되는 경우를 검증한다.
        - [x] 쉼표가 비정상적으로 입력되는 경우를 검증한다.
    - Car 도메인 단에서 검증
        - [x] 자동차 이름이 5자 이하인지 검증한다.
        - [x] 자동차 이름이 알파벳으로 이루어져 있는지 검증한다.
    - Cars 단에서 검증
        - [x] 관리하는 자동차 이름이 중복되는지 검증한다.

### 자동차 생성 기능

- [x] 자동차의 객체를 생성한다.
    - [x] 이름 및 전진 횟수를 저장하는 필드를 추가한다.
    - [x] 객체 생성 시 이름을 저장하는 생성자를 구현한다.
    - [x] 구분자를 기준으로 자동차 이름을 추출해 자동차들을 생성한다.
        - 생성된 자동차 리스트를 반환

### 총 횟수 요청 문구 출력 기능

- []전진을 시도하는 총 횟수의 입력을 요청하는 문구를 출력한다.

### 총 횟수 입력 기능

- []뷰에서 총 시도 횟수를 입력 받는다.
- []입력의 유효성을 검증한다.
    - []숫자로 구성된 입력인지 검증한다.
    - []숫자의 값이 1보다 크거나 같은지 검증한다.

### 랜덤 숫자 생성 기능

- []랜덤 숫자 생성 객체를 생성한다.
- [] 0부터 9까지 무작위 숫자를 생성하여 반환하는 함수를 구현한다.

### 자동차 전진 기능

- []입력 받은 횟수만큼 자동차의 전진을 시도한다.
- []자동차 총 개수 만큼 전진을 시도하는 함수를 호출한다.
- []각 자동차가 전진할 것인지 판단하는 함수 구현한다.
    - 4 이상이면 자동차는 전진한다.
    - 4보다 작다면 자동차는 전진하지 않는다.
- []전진 함수를 구현한다.

### 자동차의 전진 후 상태 출력 기능

- []모든 자동차의 전진을 시도한 후의 전진 상태를 출력한다.
- []toString()을 오버라이딩 하여 자동차의 전진 상태를 출력하는 함수를 호출한다.

### 우승자를 찾아 출력하는 기능

- []모든 자동차의 전진 횟수 중 최대 값을 구한다.
- []최대 값을 가지고 있는 차를 모두 찾아 리스트로 반환한다.
- []뷰에서 리스트를 가지고 우승자를 출력한다.
